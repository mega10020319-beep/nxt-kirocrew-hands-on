# 学科 AI 実習の集まりのご案内

## 概要

学科の仲間と一緒に AI を実際に使ってみる実習の集まりを開催します。定員は12名で、AI 実習が初めての学生も参加できます。英語および日本語の案内は、集まりの情報を理解していただくために提供するものです。日本語の案内を読んでも、当日の案内と実習はすべて韓国語で行われます。

## 集まりの情報

| 項目 | 内容 |
| --- | --- |
| 日程 | 2026年10月16日 18:30～20:00（韓国時間 Asia/Seoul） |
| 場所 | 学生会館 集会室 |
| 定員 | 12名 |
| 持ち物 | 個人のノートパソコンと充電器 |
| Wi-Fi | 集まりの会場で Wi-Fi を利用できます |
| 参加費 | 無料 |
| 進行言語 | 案内・実習ともに韓国語 |
| 対象 | AI 実習が初めての学生も参加可能 |

案内に記載されるすべての時刻は韓国時間です。参加される際は、個人のノートパソコンと充電器をご準備ください。持ち物の案内を読み、ご自身が使うノートパソコンと充電器をご用意いただければ大丈夫です。Wi-Fi のパスワードや別途の接続方法は、この案内には含まれていません。

## 申し込み方法

参加を希望する学生は、2026年10月14日 18:00（韓国時間）までに学科のグループチャットに名前を書き込んでください。別途の申し込みリンクは提供しません。日付と締め切り時刻を確認したうえで、案内された方法に従ってお申し込みください。
